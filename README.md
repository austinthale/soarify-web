# Soarify Website

A modern, responsive website for Soarify featuring Home, About, Blog, and Contact pages.

## 📋 Overview

Soarify-web is a lightweight, frontend-focused website built with HTML, CSS, and JavaScript. The site is designed to be fast, accessible, and easy to maintain.

## 📁 Project Structure

soarify-web/
├── index.html          # Home page
├── about.html          # About page
├── blog.html           # Blog page
├── contact.html        # Contact page
├── css/                # Stylesheets
├── js/                 # JavaScript files
└── README.md           # This file

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Clean, semantic HTML structure
- Optimized CSS for fast loading
- Minimal JavaScript for enhanced interactivity
- Easy to customize and maintain

## 🛠️ Technologies

- **HTML** (77.2%) - Semantic markup and page structure
- **CSS** (17%) - Responsive styling and layouts
- **JavaScript** (5.8%) - Interactive features and functionality

## 📄 Pages

- **Home** - Landing page with key information and call-to-action
- **About** - Learn more about Soarify and our mission
- **Blog** - Articles and updates from the team
- **Contact** - Get in touch with us
